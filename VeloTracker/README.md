# 🚲 VeloTracker

Локальный журнал технического обслуживания велосипеда, покупок запчастей и ежедневного пробега. WPF / C# / .NET 10.

## Возможности MVP
- События обслуживания: смазка цепи, покрышка, цепь, тормозные колодки, камера.
- Покупки и замена деталей: маячок, задний переключатель, трещотка, кассета, педали.
- Событие пробега за день с проверкой километража.
- Дата, поле модели/бренда/артикула, примечание и стоимость.
- История событий, удаление записей, экспорт журнала в JSON.
- SQLite + Dapper; параметризованные SQL-запросы.
- MVVM через CommunityToolkit.Mvvm, DI через `IHost`, single-instance Mutex.
- Настройки Light/Dark/System, фонового изображения и параметров текстуры сохраняются в `%AppData%`.

> MVP-ограничения: настройки фонового изображения, цвета/прозрачности и замощения сейчас сохраняются, но визуальное применение этих параметров к основному окну ещё не подключено. Значки для событий сейчас — Unicode emoji; позднее их можно заменить единым SVG icon pack.

## Требования
- Windows 10/11
- .NET 10 SDK
- Visual Studio 2026 с workload «.NET Desktop Development» либо `dotnet` CLI

## Сборка
Из папки репозитория:

```powershell
dotnet restore .\VeloTracker.slnx
dotnet build .\VeloTracker.slnx -c Debug
dotnet run --project .\VeloTracker\VeloTracker.csproj
```

## Хранение данных
- Настройки: `%AppData%\VeloTracker\settings.json`
- База событий и логи: `%LocalAppData%\VeloTracker\`
- Пользовательские данные не сохраняются рядом с EXE.

## Экспорт
JSON содержит список событий, включая тип, дату, пробег, стоимость, детали и комментарии. GPX не применяется, поскольку приложение ведёт журнал обслуживания и поездок без GPS-координат.
