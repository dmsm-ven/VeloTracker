# 🚲 VeloTracker

Локальный WPF-журнал обслуживания велосипеда, покупок и установки деталей, а также ежедневного пробега. C# / .NET 10.

## Возможности
- Три раздельные категории: обслуживание/расходники, покупка/установка детали, пройденное расстояние.
- Для обслуживания — предопределённые виды работ и примечание.
- Для детали — тип детали с иконкой, модель/бренд/артикул, стоимость и примечание.
- Для пробега — только дата и поле километража.
- История событий, удаление записей, общее число поездок и суммарный пробег.
- SQLite + Dapper; MVVM через CommunityToolkit.Mvvm; DI через `IHost`.
- WPF-UI 4.3: Fluent System Icons, UI controls, динамическая тема Light/Dark/System.
- Фоновое изображение главного окна, цвет и прозрачность карточек, замощение и масштаб текстуры. Настройки внешнего вида применяются сразу; «Отмена» возвращает прежнее состояние.

## Требования
Windows 10/11, .NET 10 SDK, Visual Studio 2026 или `dotnet` CLI.

## Сборка
```powershell
dotnet restore .\VeloTracker.slnx
dotnet build .\VeloTracker.slnx -c Debug
dotnet run --project .\VeloTracker\VeloTracker.csproj
```

Настройки: `%AppData%\VeloTracker\settings.json`. База и логи: `%LocalAppData%\VeloTracker\`.
